숏폼 등록 가이드

상품 등록 → 영상 등록 순서로 진행합니다.

무엇을 하는 작업인가

HCMS에서 등록한 온라인 과정에 세로형 맛보기 영상을 별도로 매핑해, 연수원 학습자 화면에 노출시키는 작업입니다. 영상 자체를 새 과정으로 만드는 것이 아니라, 이미 있는 과정에 맛보기를 붙이는 개념입니다.

  • 선행 조건 — 대상 과정이 이미 존재해야 합니다. 과정이 없으면 매핑할 과정코드가 없어 숏폼으로 등록되지 않습니다.
  • 입력 기준 — 이 가이드에 언급된 항목은 필수로 입력하고, 나머지 항목은 업로드하는 컨텐츠 성격에 맞게 입력하면 됩니다.
1

상품 등록

어드민 > 마이크로러닝 관리 > 상품관리 > 4. 상품·컨텐츠 동시등록

https://admin.hunet.co.kr/Mall/Goods/Imagine/Contents/GoodsContentsWrite.aspx
  • 타입 구분 — ‘쇼츠’ 선택 후 나머지 항목 입력
  • 과정코드 — 반드시 입력
  • 입력한 과정코드를 기준으로 연수원에 매핑되어, 해당 과정에 업로드한 세로형 맛보기가 노출됩니다.
과정코드를 입력해야 숏폼(세로형 맛보기)으로 등록됩니다. 입력하지 않으면 쇼츠로만 등록됩니다.
2

영상 등록

어드민 > 마이크로러닝 관리 > 상품관리 > 2. 온라인 컨텐츠 관리

1번에서 상품을 등록한 뒤 진행합니다.

  • 1번에서 등록한 상품명으로 검색 후 상세 진입
  • MP4 업로드 → 영상 업로드 후 닫기
  • 컨텐츠 번호는 상세 화면 최상단에 표시된 번호입니다.
  • 동영상비율 — 세로모드로 설정
  • 그 외 항목은 자유 입력

숏폼 맛보기 노출 기준

과정코드를 입력해 등록한 경우에만 해당됩니다.

형태온라인 과정의 세로형 맛보기, 해당 과정으로 연결
