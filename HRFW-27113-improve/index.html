1. 요구사항 요약

새로 연 기능이 쓸 만한지 교육담당자에게 에듀매니저 팝업으로 물어보는 기능을 만듭니다. 운영자가 직접 문항을 만들고, 설문을 등록해 대상에게 진행하고, 결과를 봅니다.

누구에게기업의 교육담당자 (에듀매니저 계정 보유자)
무엇을기능개선 설문 — 새로 연 기능이 쓸 만한지
운영 주체개별 기업은 자기 기업 담당자에게 · 휴넷(0번 기업)은 고객사를 골라 그 담당자에게
어디에에듀매니저 — 개별 기업 / 0번 기업 양쪽에 메뉴를 만듭니다

2. 참여 흐름

기능개선 설문
에듀매니저 안에서만 돕니다
에듀매니저 특정 페이지 접근→ 팝업→ 좋아요 / 아쉬워요 선택→ 그 갈래의 문항에 응답

로그인한 계정으로 답하므로 응답자 정보를 따로 묻지 않습니다. 필요하면 독려 메일을 보내 접속을 유도합니다 — 메일의 버튼은 에듀매니저로 데려갑니다.

메일 템플릿은 시스템이 기본 한 벌을 들고 있습니다 — [메일 보내기]에서 고르면 본문에 채워집니다. 빈 에디터 앞에 앉히면 {{설문참여링크}}가 빠진 메일이 나가기 때문입니다. 디자인이 바뀌면 그 HTML을 갈아끼워 반영하고, 화면에서 템플릿을 고치는 칸은 두지 않습니다.

5. 핵심 정책

구분내용
참여 채널
  • 에듀매니저 팝업 하나 — 끄는 칸 없음
  • 로그인한 계정으로만 답함 — 에듀매니저 밖에서 답하는 길은 두지 않음
  • [메일 보내기]는 참여 독려용 — 메일의 버튼이 에듀매니저로 데려감
  • 로그인 전에 메일 링크를 눌렀을 때 로그인 뒤 그 메뉴로 이어 보낼 수 있는지 확인 필요
대상 지정
  • 팝업 대상과 메일 받는 사람은 같은 명단에서 나옴 — 메일은 그중 일부만 고를 수도 있음
  • 개별 기업은 사람, 0번 기업은 기업 + 그 기업의 담당자
  • 0번 [전체 기업]은 담당자 개별 선택 불가 — 노출 시점 명단 사용
  • 기업 지정일 때만 고른 담당자를 설문에 저장 — 이후 등록된 담당자는 자동 포함되지 않음
중복 응답
  • 한 사람이 한 번만 응답 (중복 응답 불가)
  • 판정 기준은 로그인 계정
  • 재진입 시 「이미 응답하셨습니다」 안내 — 다시 받으려면 운영자가 [설문 초기화]
노출 우선순위
  • 한 번 진입에 팝업 1개 — 답하든 닫든 그 진입은 종료
  • 다음 설문은 해당 메뉴 재진입 시 노출
  • 순서: 개별 기업 설문 → 종료일 빠른 순 (동일 시 설문번호 순)
  • 연속 노출 금지 — 닫기 직후 재노출은 반사적으로 닫힘
  • 사용여부가 미사용이거나 기간 밖인 설문은 노출 대상에서 제외
문항
  • 문항은 갈래를 갖지 않음 — 설문 등록에서 좋아요 / 아쉬워요 자리와 순서를 지정
  • 담은 순서 = 응답 화면의 단계 순서
  • 문항은 기업별로 따로 쌓임 — 다른 기업 문항은 보이지 않음
  • 0번 기업도 하나의 기업으로 자기 문항 보유
표준 문항 제공
  • 기본 문항 5개 제공 (좋아요 3 · 아쉬워요 2)
  • 기업 개설 시 자동 복사, 이후 [표준 문항 불러오기]로 수동 복사
  • 복사 후에는 기업 소유 — 원본 수정이 덮어쓰지 않음
  • 설문 등록 시 [표준 템플릿 불러오기]로 구성 일괄 적용
  • 보관 위치 · 세팅 방법 미정 확인 필요
결과 권한
  • 개별 기업은 자기 기업 설문만 조회
  • 0번 기업은 전체 조회 — 자기 등록분 + 개별 기업 진행분
  • 0번 기업 설문 결과는 개별 기업에서 조회 불가
개인정보
  • 수집 항목은 기업 · 성명 · 아이디 — 로그인 계정에서 가져옴
  • 연락처는 수집하지 않음 · 개인정보 수집 동의 화면 없음
  • 집계 화면에는 표시하지 않고 다운로드 엑셀에만 포함
